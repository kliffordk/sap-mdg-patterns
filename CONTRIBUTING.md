# Contributing

Thanks for helping make these patterns more accurate and more useful.

## Ways to contribute

- **Corrections** — wrong object name, outdated behaviour, a better approach. Open an issue with your release and what you observed.
- **Release notes** — "On S/4HANA 20xx this works differently because…" is very valuable.
- **Pattern ideas** — open an issue describing the problem you faced and the options you considered.
- **New patterns** — open an issue first so we can agree on scope, then submit a pull request using [the template](templates/PATTERN_TEMPLATE.md).

## Rules for all contributions

1. **Write from scratch.** Don't submit code or configuration copied from a client, employer or partner system — even with names removed.
2. **No confidential information.** No client names, internal system names, business data or screenshots from real systems.
3. **Don't paste SAP source code.** Reference SAP classes, interfaces and BAdIs by name; write your own implementations.
4. **Say what you tested.** Mark code as *Tested* (with release) or *Illustrative*.
5. **Keep it practical.** Explain the decision and the trade-offs, not just the steps.
